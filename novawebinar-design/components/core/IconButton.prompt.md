Circular icon button — the signature Novawebinar control for card actions (filter, comment, expand ↗) and toolbars.
```jsx
<IconButton icon="sliders-vertical" variant="accent" />
<IconButton icon="arrow-up-right" />
```
- Card header trio: orange sliders + light message-circle-more + light arrow-up-right.
- `active` flips any variant to orange; sizes 32–48.
